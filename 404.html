微信图片自动保存助手

微信图片自动保存助手，能把微信收到的图片、视频和文件按你设定的目录和命名规则自动保存到电脑本地。

开始使用

先开本程序或先登录微信都可以。未检测到微信时列表提示「请先启动微信」；挂接成功后提示「已检测到微信正在运行」。

主窗口下方可改保存目录，点「设置目录」选择文件夹，点「打开目录」查看已保存文件。

顶部搜索框按来源、发送者或文件名过滤。双击记录用系统默认程序打开，右键可打开文件、文件夹或清空列表（不会删除磁盘文件）。

点右上角关闭程序会缩到托盘并继续保存；要退出请用托盘菜单里的「退出」。

自测请用手机或其他电脑往本机微信发文件，本机自己发出去的内容一律不收。

更换程序文件后，请先退出本程序和微信再重新打开，新规则才会生效。

保存路径格式

在「设置」里选择，日期形如 2026-09-27，月份形如 2026-09。会话层文件夹名 = 显示名 + 8 位大写十六进制，用来区分同名会话。

保存路径格式对照表
选项目录结构

昵称\日期\文件昵称\日期\
昵称\文件昵称\
群名\日期\成员\文件群名\日期\成员\
群名\成员\文件群名\成员\

后两种按群成员再分一层。
群聊会话名称会带括号前缀，单聊没有群成员时这一层使用会话名称。

文件名称格式

时间编号 = 年月日时分秒 + 四位序号，例如 2026092716260000。

文件名称格式对照表
选项示例
文件名(发送者)_时间编号图片(张三)_202609271626.jpg
时间编号_文件名(发送者)202609271626_图片(张三).jpg
文件名(群名_发送者)_时间编号图片(群_张三)_202609271626.jpg
文件名_时间编号图片_202609271626.jpg

还有带「年月日时分秒」单位的选项，会把单位写进文件名。

按名称过滤
  • 白名单：只保存名称包含关键字的会话，多个关键字用逗号或分号分隔。
  • 黑名单：名称包含关键字的会话不保存。
  • 两项都没勾选时，符合接收开关的图片、视频和文件都会保存。
  • 两者可同时使用：先命中白名单，再排除黑名单。
接收与窗口
  • 禁止接收：勾选后对应内容不再保存。
  • 自动去重：同目录已有相同内容时不再保留新的一份。
  • 开机自启：登录 Windows 后自动打开本程序。
  • 主窗口置顶：主窗口保持在其他窗口前面。

点「确定」后立即按新设置保存，取消则保持原来设置。

手机远程指令

用手机给「文件传输助手」发送下面两个词，电脑上的本程序会执行对应操作。只识别这两个词，其它文字不触发。

  • 锁屏：锁定当前 Windows 会话。
  • 关机：关闭这台电脑。发送前请确认没有未保存的工作。

常见情况
启动时提示「请先启动微信」怎么办？
打开并登录电脑微信即可，本程序会自动接上，不用重新打开助手。
出现「版本不匹配」怎么解决？
请换到已支持的微信版本；或下载最新版助手，然后重启微信。
列表是空的，为什么？
程序只显示本次打开之后新收到的文件，不会回扫以前的聊天记录。右键「清空目录」也会把当前列表清掉。
某张图没有出现，可能是什么原因？
检查是否被白名单、黑名单或「禁止接收」挡住，以及微信是否已经登录。
保存位置不对，如何排查？
看主窗口下方的目录，以及设置里的路径格式。文件在子文件夹里，不总是直接放在保存目录根下。
默认保存目录在哪里？
默认保存目录是「图片\WxArchiver」。设置保存在当前 Windows 用户下，换一台电脑需要重新设置。
